---
title: Instalar
---

**AwesomeB** dispone de binarios para macOS, Linux y Windows, ¡pero ojo! Las versiones de Linux y Windows no están debidamente probadas.

Actualmente solo puedes encontrar los binarios en la página de [releases](https://github.com/francescarpi/awesomeb/releases) de GitHub.

Ten en cuenta que la aplicación tiene un sistema de auto-actualización, es decir, que una vez instalada, si hay nuevas versiones, serán notificadas al usuario y podrá instalarlas.
