---
title: Previsualizar un sitio web
---

Mientras navegas por un sitio web y encuentras un enlace, a menudo querrás previsualizarlo antes de abrirlo como nueva pestaña.

Para previsualizarlo:

* macOS: `Opt+<click>`

![Vista previa de un enlace](../../../../assets/tab-preview.png)

Dentro de la misma pestaña aparecerá una nueva vista con la previsualización del sitio web (1) para poder navegar y acabar de decidir si lo descartas o no. Verás que bajo el título de la pestaña se muestra el icono de un ojo (3) para indicar que esa pestaña tiene una previsualización abierta.

Tienes tres acciones disponibles (2):

* Hacer clic sobre la cruz o `esc` para descartarlo.
* Hacer clic sobre las flechas de maximizar o `enter` para abrirlo como nueva pestaña.
* Hacer clic en el icono de split para abrir el enlace con formato [dividido](/es/tabs/split/).
