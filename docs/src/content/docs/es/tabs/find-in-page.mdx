Puedes buscar un texto dentro de la página:

![Buscar dentro de una página](../../../../assets/find-in-page.png)

* Haciendo clic en la cruz (1) o `escape` sales.
* En el campo de texto (2) introduce el texto que quieres buscar.
* Si hay varios resultados puedes saltar al siguiente o anterior (3).
