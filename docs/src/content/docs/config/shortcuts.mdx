title: Shortcuts
---

This is where you can customise the shortcuts so that you feel as comfortable as possible using **AwesomeB**.

![Shortcuts configuration](../../../assets/config-shortcuts-1.png)

The first thing you can do is set the default keymap. Currently there is only one, **Generic ISO**, but the plan is to add more in the future, for example **Generic ANSI**.

Once you have chosen the keymap that best fits your keyboard layout, you can even customise each shortcut by clicking on it and setting the new shortcut:

![Shortcut configuration](../../../assets/config-shortcuts-2.png)
