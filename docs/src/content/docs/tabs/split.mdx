Up to **three** tabs can be opened in split format (in the same *tab container*).

![Two tabs in split format](../../../assets/tab-split-1.png)

![Three tabs in split format](../../../assets/tab-split-2.png)

:::note
When a *tab container* contains more than one tab, a dashed border (1) is shown.
:::

Also, there are currently two formats, horizontal and vertical.

![Tabs in horizontal and vertical formats](../../../assets/tab-split-4.png)

## Change layout or size

When tabs are split, an icon appears at the top bar to open the options menu.

There you can:

* Change the format (horizontal, vertical).
* Rotate the tabs to the right.
* Split the tabs into individual tabs.
* Change the size. The `Change Layout Size` command also exists.

![Layout options menu](../../../assets/tab-split-3.png)

:::note
Currently, the size can only be changed through the menu — the *drag & resize* feature doesn't exist yet, but it may be added in the future.
:::
