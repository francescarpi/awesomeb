---
title: Install
---

**AwesomeB** provides binaries for macOS, Linux, and Windows, but be careful! The Linux and Windows versions are not properly tested.

You can currently only find the binaries on the [releases](https://github.com/francescarpi/awesomeb/releases) page on GitHub.

Note that the application has an auto-update system, meaning that once installed, if there are new versions, the user will be notified and can install them.
