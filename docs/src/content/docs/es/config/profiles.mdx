---
title: Perfiles
---

Los perfiles son **contenedores** de aislamiento de navegación: cada perfil mantiene sus propias cookies, caché y datos de sesión, de modo que puedes tener contextos separados (trabajo, personal, pruebas) dentro del mismo navegador sin que se mezclen entre sí.

Por defecto, **AwesomeB** incluye dos:

* **Default**
* **Private**: Trabaja exclusivamente en memoria. No persiste cookies, caché ni ningún dato de navegación en disco: cuando cierras la sesión, todo se borra. Pensado para ordenadores compartidos, operaciones puntuales con datos sensibles o para navegar sin dejar rastro.

Desde este apartado de la configuración podrás crear perfiles adicionales, por ejemplo uno personal o uno de trabajo.

![Configuración de perfiles](../../../../assets/config-profiles.png)

Para cada perfil puedes definir un **nombre** y un **color**.

:::note
Actualmente, si se añade o se elimina un perfil, es necesario reiniciar el navegador.
:::
