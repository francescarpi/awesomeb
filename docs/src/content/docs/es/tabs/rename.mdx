<FeatureAccess entity="renombrar" command="renameTab" contextMenu="contextTab.rename" />

Esta es una funcionalidad muy útil cuando quieres cambiar el título del sitio web por uno personalizado. El nombre personalizado prevalecerá sobre el título original.

![Diálogo para renombrar](../../../../assets/tab-rename-1.png)

El nuevo nombre será visible en todas partes: *sidebar*, listado de pestañas, etc.

![Nombre personalizado en el listado](../../../../assets/tab-rename-2.png)

:::note
Si quieres volver al título original, solo tienes que borrar el título personalizado.
:::
