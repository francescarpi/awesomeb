---
title: Dividers
---

Dividers are just a visual element (dashed line) that separates one *tab container* from another. They are useful when you have many and you want to separate them by context.

![Dividers](../../../assets/tab-divider.png)

Through the **context menu** you can:

* Add a divider
* Remove a divider
* Remove all the dividers in the desktop.

You also have the following commands available:
* Add Tab Container Divider
* Remove All Desktop Dividers
* Remove Tab Container Divider
