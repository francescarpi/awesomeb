Puedes moverlo a la derecha o a la izquierda dentro del listado de escritorios. La numeración se actualiza automáticamente para mantener el orden correlativo.

## Arrastrar y soltar

También puedes arrastrar un escritorio sobre otro para intercambiar sus posiciones. El escritorio que arrastras sigue al puntero como un círculo, y el escritorio sobre el que lo sueltas se resalta para mostrar dónde caerá.

La numeración se actualiza automáticamente para mantener el orden correlativo.
