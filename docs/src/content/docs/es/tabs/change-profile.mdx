Los perfiles se explican [aquí](/es/config/profiles/).

Cuando cambias el perfil de una pestaña activa, esta pasa a utilizar las cookies, caché y datos de sesión del nuevo perfil. Es útil para acceder a un mismo sitio web con cuentas diferentes sin necesidad de abrir ventanas separadas.
