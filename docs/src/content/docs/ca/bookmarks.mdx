Com sabràs d'altres navegadors, la funcionalitat de preferits et permet emmagatzemar de forma estructurada llocs web per a poder accedir-hi en futures ocasions.

## Afegir un preferit

Només és possible utilitzant el menú contextual quan una pestanya està activa:

![Preferits al menú contextual](../../../assets/bookmarks-1.png)

### Afegir aquí

Et permet desar el lloc web a la carpeta seleccionada. Inicialment, com que no n'hi ha cap, es desen al *root*.

![Desar aquí](../../../assets/bookmarks-2.png)

### Crear carpeta i afegir

Et permet crear una nova carpeta dins la carpeta on estiguis (la primera vegada és *root*) i desar el lloc web directament allà.

![Crear carpeta i desar](../../../assets/bookmarks-3.png)

Amb aquest exemple veuràs clarament el perquè del *Add here...* i *Create folder here and add...*. Si tornes a accedir a l'opció d'afegir preferit hi veuràs la nova carpeta creada en l'exemple, i el següent lloc web el pots desar a *root* o dins *Utils* o les carpetes que tinguis.

![Carpeta creada](../../../assets/bookmarks-4.png)

## Desar les pestanyes d'un escriptori

Pots desar totes les pestanyes d'un escriptori als preferits d'una sola vegada. Fes clic dret en un escriptori de la barra lateral i tria l'opció *Desa les pestanyes de l'escriptori als marcadors*. L'opció només està disponible quan l'escriptori té pestanyes, estiguin actives o suspeses.

<FeatureAccess entity="desar les pestanyes d'un escriptori" command="bookmarksAddDesktop" contextMenu="contextDesktop.addTabsToBookmarks" />

El modal mostra cada pestanya d'aquest escriptori perquè triïs quines vols desar, seleccionis una carpeta i posis un nom si en crees una de nova. Després de desar-les, les pestanyes es tanquen.
