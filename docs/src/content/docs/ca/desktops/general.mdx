---
title: Escriptoris
---

Els escriptoris són una manera d'organitzar pestanyes (es podria dir que són com grups).

Per defecte n'hi ha 5, però en pots crear fins a 9.

Estan enumerats sent el primer el número 1 i l'últim el número 9, però, si vols, els pots anomenar.

Llegeix els següents apartats per saber-ne totes les funcionalitats.
