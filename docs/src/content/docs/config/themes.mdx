Here you will find two things:

1. Create new visual themes for desktops
2. Change the visual theme for the user interface

![Themes configuration](../../../assets/config-themes.png)

## Desktop themes

Later, in the desktops section, you will see how to change the visual theme of a desktop (and what a desktop is). By default, **AwesomeB** includes a few predefined themes for desktops:

* Blue
* Purple
* Emerald
* Pink
* Orange
* Black

If you wish, you can also create more to your liking.

## UI theme

The user interface refers to, for example, the settings page, modal windows, etc. If you wish, you can also change this theme to your liking.
