També podràs editar-la fent clic sobre la barra d'adreces. Sé que el comportament no és l'esperat, ja que normalment esperaries un camp de text lliure.

Veuràs un modal amb dues opcions de modificació:

![Modal d'edició de la URL](../../../../assets/tab-edit-url.png)

1. **Modificació simple**: canvies o enganxes la nova URL.
2. **Modificació complexa**: la URL està dividida en parts, permetent-te modificar només la part que desitgis. També pots afegir o modificar els *queryparams*.
