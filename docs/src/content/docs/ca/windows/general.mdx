Una finestra està identificada amb un número (1). Així, si mous una pestanya a una altra finestra, pots identificar-la millor.

![Finestra](../../../../assets/windows-1.jpeg)

## Colapsar panell esquerre (sidebar)

<FeatureAccess entity="col·lapsar el panell esquerre" shortcut="toggleSidebar" command="toggleSidebar"/>

També pots fer-ho fent clic al botó de col·lapsar (2).

![Colapsar panell](../../../../assets/windows-2.png)

El panell i el lloc web es redimensionaran amb una transició suau.

## Maximitzar àrea

<FeatureAccess entity="maximitzar un lloc web" shortcut="toggleMaximizeArea" command="toggleMaximizeArea"/>

És útil quan vols que el lloc web ocupi tot l'espai disponible.

![Maximitzar àrea](../../../../assets/windows-3.png)

:::note
Aquestes transicions segueixen la preferència de moviment reduït del teu sistema operatiu. Si la tens activada, el panell i el lloc web es redimensionaran a l'instant.
:::
