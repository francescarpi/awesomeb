As mentioned in the [previous section](/tabs/close/), when a website is closed, it remains invisible for a few days in case you want to reopen it.

<FeatureAccess entity="reopen a web" macOS="Cmd+Shift+t" command="openClosed" menu="file.openRecentlyClosed" />

If you use the command, a modal will appear for you to filter/select which website you want to reopen.

![Reopen a web](../../../assets/open-closed-2.png)

## Clear closed tabs

If you want to clear the history of all closed tabs, you can do so through the **Clear Closed Tabs** command. It will ask for confirmation before proceeding:

![Clear closed tabs](../../../assets/open-closed-3.png)
