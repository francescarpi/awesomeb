Els temes visuals dels escriptoris ens permeten assignar un tema diferent a cada un d'ells per poder-los diferenciar més fàcilment.

Per exemple, podem tenir el tema blau a l'escriptori 1 i el violeta al 2.

![Tema blau](../../../../assets/desktop-theme-1.jpeg)

![Tema violeta](../../../../assets/desktop-theme-2.jpeg)

<FeatureAccess entity="tema de l'escriptori" command="Desktop Theme" contextMenu="Change theme" />

T'apareixerà un modal amb el llistat de temes disponibles:

![Selecció de tema](../../../../assets/desktop-theme-3.png)

:::note
Recorda que pots modificar o afegir més temes a la [configuració](/ca/config/themes/).
:::
