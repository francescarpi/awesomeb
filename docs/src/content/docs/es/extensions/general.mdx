---
title: Extensiones
---

**AwesomeB** permite, aunque de forma un poco rudimentaria, extensiones de *Chrome Store*.

:::danger
¡Cuidado! Todavía están *work in progress* y son bastante inestables. No están implementadas todas las APIs ni hay integración con el *Chrome Store*.
:::

### Comportamiento de las APIs disponibles

Las siguientes APIs de extensiones están disponibles con estos comportamientos:

* `tabs.query({ active: true })` devolverá solo las pestañas activas.
* `tabs.query` devolverá su resultado y podrá invocar opcionalmente un callback con las pestañas.
* `cookies.getAll` devolverá las cookies y podrá invocar opcionalmente un callback con ellas.

:::note
Sé que existen algunas librerías para incorporar extensiones a *Electron*, así como para descargarlas del *Chrome Store*, pero hay algunas limitaciones de licencias y he preferido hacer mi propia implementación.
:::
