Welcome to **AwesomeB**!

This browser was born from a personal need for a **Chromium-based** browser with native container functionality.

What are containers? Containers are a feature that lets you run different browsing sessions in isolation, which is useful for separating accounts, work sessions, and privacy.

From there, the project has evolved to include many other features and capabilities that enhance the browsing experience.
