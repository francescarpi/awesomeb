---
title: Install
---

**AwesomeB** provides binaries for macOS, Linux, and Windows, but be careful! The Linux and Windows versions are not properly tested.

You can currently only find the binaries on the [releases](https://github.com/francescarpi/awesomeb/releases) page on GitHub.

The application [auto-updates](/autoupdate/): when there are new versions, you'll be notified and can install them.

## First run

When you launch **AwesomeB** for the first time, you'll see the [first steps](/firststeps/) screen to configure your first search engine and other basic options.
