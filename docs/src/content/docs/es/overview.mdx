¡Bienvenido a **AwesomeB**!

Este navegador nació de una necesidad personal de tener un navegador, **basado en Chromium**, con la funcionalidad de contenedores de forma nativa.

¿Qué son los contenedores? Los contenedores son una característica que permite ejecutar diferentes sesiones de navegación de forma aislada, algo que resulta útil para separar cuentas, sesiones de trabajo y privacidad.

A partir de aquí, el proyecto ha evolucionado para incluir muchas otras funciones y características que mejoran la experiencia de navegación.
