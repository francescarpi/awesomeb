<FeatureAccess entity="rename" command="Rename Tab" contextMenu="Rename" />

This is a very useful feature when you want to change a website's title to a custom one. The custom name will take precedence over the original title.

![Rename dialog](../../../assets/tab-rename-1.png)

The new name will be visible everywhere: *sidebar*, tabs list, etc.

![Custom name in the list](../../../assets/tab-rename-2.png)
