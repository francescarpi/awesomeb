# AwesomeB

## Develop

Install dependencies and set up pre-commit hooks:

```bash
pnpm install
pre-commit install
```

Run the development server:

```bash
pnpm dev
```

## Features

- Organize tabs into customizable desktops.
- Desktop's theme customization.
- Rename desktops.
- Save and restore tab sessions.
- Maximize area for focused work.
- Access to the API using command palette.
- Tab profile management.
