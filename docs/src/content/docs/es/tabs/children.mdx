---
title: Pestañas hijas
---

Imagina el siguiente escenario.

En el *sidebar* tienes tres pestañas: Jira, Pestaña 2, Pestaña 3. Jira abre todos los tickets como `target="_blank"`. Esto significa que se crearán nuevas pestañas al final, después de la Pestaña 3.

Esto es muy incómodo porque quedan pestañas desorganizadas y es por este motivo que existe la siguiente funcionalidad.

Abre el menú contextual y selecciona la opción **Open target blank links as a child...**.

![Activar pestañas hijas](../../../../assets/tab-child-1.png)

A partir de ahora, todos los sitios web que se abran desde esta pestaña quedarán como hijos.

![Ejemplo pestañas hijas](../../../../assets/tab-child-2.png)

Esto te permite mover el padre arriba o abajo manteniendo los hijos relacionados.

Además, también a través del menú contextual, tendrás la opción de cerrar todos los hijos.

![Cerrar todos los hijos](../../../../assets/tab-child-3.png)
