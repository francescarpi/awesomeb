Pots cercar un text dins la pàgina:

![Cercar dins una pàgina](../../../../assets/find-in-page.png)

* Fent clic a la creu (1) o `escape` surts.
* Al camp de text (2) introdueix el text que vols cercar.
* Si hi ha diversos resultats pots saltar al següent o anterior (3).
* Si la barra ja és oberta i tornes a executar l'ordre, el text actual roman seleccionat, de manera que pots escriure un terme nou per substituir-lo.
