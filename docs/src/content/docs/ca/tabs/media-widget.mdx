---
title: Widget de media
---

Si estàs a un lloc web que conté un *MediaSession*, per exemple *Youtube* i te'n vas a un altre, apareixerà el següent widget a baix del panell esquerre (*sidebar*) el qual et permetrà gestionar-lo.

![Widget de media](../../../../assets/tab-media-widget.jpeg)

1. Fent clic sobre el *favicon* tornaràs al lloc web que està reproduint el *MediaSession*.
2. Pots pausar o reproduir el media.
3. Pots mutejar/unmutejar l'àudio.

Això és especialment útil quan vols continuar escoltant música o un podcast mentre treballes en una altra pestanya.
