To access a specific desktop, since they are numbered, you can do it with:

<FeatureAccess entity="access the first desktop" shortcut="selectDesktop1" />

<FeatureAccess entity="access the second desktop" shortcut="selectDesktop2" />

... and so on up to the last one.

## Previous/Next

If you want to move between desktops:

<FeatureAccess entity="previous desktop" shortcut="previousDesktop" command="previousDesktop" />

<FeatureAccess entity="next desktop" shortcut="nextDesktop" command="nextDesktop" />

## Search for a desktop

With the following key combination a modal appears with all desktops:

<FeatureAccess entity="search for a desktop" shortcut="findDesktop" />
