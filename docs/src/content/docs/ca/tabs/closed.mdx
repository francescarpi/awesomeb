Com s'ha comentat a l'[apartat anterior](/ca/tabs/close/), quan un lloc web es tanca, roman invisible durant uns dies per si vols reobrir-lo de nou.

<FeatureAccess entity="reobrir un lloc web" macOS="Cmd+Shift+t" command="Open Closed Tab" menu={['File', 'Open recently closed tab']} />

Si utilitzes la comanda, t'apareixerà un modal per a filtrar/seleccionar quin lloc web vols reobrir.

![Reobrir un lloc web](../../../../assets/open-closed-2.png)

## Netejar les pestanyes tancades

Si vols netejar l'historial de totes les pestanyes tancades, pots fer-ho a través de la comanda **Clear Closed Tabs**. Et demanarà confirmació abans de procedir:

![Netejar les pestanyes tancades](../../../../assets/open-closed-3.png)
