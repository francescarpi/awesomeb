**AwesomeB** offers a command interface to use any of the available features in a faster, more direct way.

<FeatureAccess entity="commands" menu="file.performCommand" shortcut="performCommand"/>

You can also access it by clicking here:

![Commands button](../../assets/commands-2.png)

When you trigger the command palette, you'll see a modal window with an extensive list of all the features you can use. You can:

1. Filter them by typing text.
2. `Shift+j` / `Shift+k` / `Arrow Up` / `Arrow Down`: to navigate to the previous or next one.
3. **Enter**: select or execute.

![Command palette](../../assets/commands.png)
