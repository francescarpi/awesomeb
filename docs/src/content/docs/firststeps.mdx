---
title: First steps
---

When you launch **AwesomeB** for the first time, what you'll see is a welcome view like this:

![Welcome screen](../../assets/welcome1.jpeg)

Click **Initial Setup** to fill in the minimum configuration required for **AwesomeB** to work.

![Initial setup](../../assets/welcome2.png)

The first thing you need to do is configure at least one search engine, like the one shown in the example:

* Name: Moogle
* URL: https://moogle.com/search?q={query}

:::note
For now there are no predefined search engines: you have to configure one manually.

Free ones may be added in the future, and those from sponsoring companies could be included by default.
:::

Once you've configured the first search engine, you can start the browser normally.

:::note
If you want to configure more search engines, you can do so through the settings page.
:::
