import FeatureAccess from '../../../../components/FeatureAccess.astro'

<FeatureAccess entity="suspendre un escriptori" command="Suspend Desktop" contextMenu="Suspend all tabs" />

Aquesta acció suspendrà totes les pestanyes actives de l'escriptori.

A diferència de suspendre-les [pestanya a pestanya](/ca/tabs/close/#suspendre), aquí suspens tot l'escriptori d'una sola vegada. Les pestanyes suspeses ocupen menys memòria i recursos, i es poden recuperar fàcilment.
