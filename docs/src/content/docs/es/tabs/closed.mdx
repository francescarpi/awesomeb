Como se ha comentado en el [apartado anterior](/es/tabs/close/), cuando un sitio web se cierra, permanece invisible durante unos días por si quieres volver a abrirlo.

<FeatureAccess entity="reabrir una web" shortcut="openRecentlyClosed" command="openClosed" menu="file.openRecentlyClosed" />

Si utilizas el comando, te aparecerá un modal para filtrar/seleccionar qué sitio web quieres reabrir.

![Reabrir una web](../../../../assets/open-closed-2.png)

## Limpiar pestañas cerradas

Si quieres limpiar el historial de todas las pestañas cerradas, puedes hacerlo a través del comando **Clear Closed Tabs**. Te pedirá confirmación antes de proceder:

![Limpiar pestañas cerradas](../../../../assets/open-closed-3.png)
