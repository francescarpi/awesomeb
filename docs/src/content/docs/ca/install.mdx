title: Instal·lar
---

**AwesomeB** disposa de binaris per a macOS, Linux i Windows, però compte! Les versions de Linux i Windows no estan degudament testejades.

Actualment només pots trobar els binaris a la pàgina de [releases](https://github.com/francescarpi/awesomeb/releases) de GitHub.

L'aplicació s'autoactualitza: quan hi hagi noves versions, t'ho notificarà i les podràs instal·lar.

## Primera execució

En iniciar **AwesomeB** per primera vegada, veuràs la pantalla de [primeres passes](/ca/firststeps/) per a configurar el primer cercador i altres opcions bàsiques.
