title: Permisos

Muchos sitios web necesitan permisos para poder operar correctamente, por ejemplo para utilizar el `localStorage` o la geolocalización, etc.

Cuando un sitio web pida autorización para utilizar un permiso, verás un modal similar a este:

![Configuración de permisos](../../../../assets/config-permissions-1.png)

Desde este apartado de la configuración podrás gestionar los permisos de los sitios web y el nivel de seguridad:

![Configuración de permisos](../../../../assets/config-permissions-2.png)

## Nivel de seguridad

Actualmente hay dos niveles de seguridad:

* **Estándar**: Para no ser muy pesado, no te pedirá permiso para algunos de los permisos más habituales. A continuación tienes la lista:
  * Sensors
  * Acelerómetro
  * Giroscopio
  * Magnetómetro
  * Sensor de luz ambiente
  * Escribir y leer desde el portapapeles
  * Pasar a modo de pantalla completa
  * Auto-reproducir un vídeo
* **Estricto**: El modo estricto te pedirá autorización para todos los permisos.

## Gestionar permisos

Desde este apartado podrás modificar el valor de cualquier permiso de un sitio web o, incluso, borrarlos todos.
