Una ventana está identificada con un número (1). Así, si mueves una pestaña a otra ventana, puedes identificarla mejor.

![Ventana](../../../../assets/windows-1.jpeg)

## Colapsar el panel izquierdo (sidebar)

<FeatureAccess entity="colapsar el panel izquierdo" macOS="Cmd+s" command="Toggle Sidebar"/>

También puedes hacerlo haciendo clic en el botón de colapsar (2).

![Colapsar panel](../../../../assets/windows-2.png)

## Maximizar el área

<FeatureAccess entity="maximizar un sitio web" macOS="Cmd+i" command="Toggle Maximize Area"/>

Es útil cuando quieres que el sitio web ocupe todo el espacio disponible.

![Maximizar área](../../../../assets/windows-3.png)
