**AwesomeB** dispone de binarios para macOS, Linux y Windows, ¡pero ojo! Las versiones de Linux y Windows no están debidamente probadas.

Descarga la última versión para tu plataforma:

<DownloadButton />

La aplicación se [auto-actualiza](/es/autoupdate/): cuando haya nuevas versiones, te lo notificará y podrás instalarlas.

## Primera ejecución

Al iniciar **AwesomeB** por primera vez, verás la pantalla de [primeros pasos](/es/firststeps/) para configurar el primer buscador y otras opciones básicas.
