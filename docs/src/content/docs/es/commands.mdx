**AwesomeB** ofrece al usuario una interfaz de comandos para utilizar cualquiera de las funcionalidades disponibles de una forma más rápida y directa.

<FeatureAccess entity="comandos" menu={['File', 'Perform Command']} macOS="Cmd+p"/>

También puedes acceder haciendo clic aquí:

![Botón de comandos](../../../assets/commands-2.png)

Al activar el disparador de comandos verás una ventana modal con un listado extenso de todas las funcionalidades que puedes utilizar. Puedes:

1. Filtrarlas escribiendo texto.
2. `Shift+j` / `Shift+k` / `Arrow Up` / `Arrow Down`: para navegar a la anterior o siguiente.
3. **Enter**: seleccionar o ejecutar.

![Lista de comandos](../../../assets/commands.png)
