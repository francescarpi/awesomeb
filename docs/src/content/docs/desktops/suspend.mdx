<FeatureAccess entity="suspend a desktop" command="suspendDesktop" contextMenu="contextDesktop.suspendAllTabs" />

This action will suspend all the active tabs of the desktop.

Unlike suspending them [tab by tab](/tabs/close/#suspend), here you suspend the entire desktop at once. Suspended tabs use less memory and resources, and can be easily recovered.
