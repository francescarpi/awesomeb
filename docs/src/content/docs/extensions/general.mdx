---
title: Extensions
---

**AwesomeB** allows, although in a somewhat rudimentary way, *Chrome Web Store* extensions.

:::danger
Heads up! They are still *work in progress* and are quite unstable. Not all APIs are implemented and there is no integration with the *Chrome Web Store*.
:::

### Available API behavior

The following extension APIs are available with these behaviors:

* `tabs.query({ active: true })` will return only active tabs.
* `tabs.query` will return its result and can optionally invoke a callback with the tabs.
* `cookies.getAll` will return the cookies and can optionally invoke a callback with them.

:::note
I know there are some libraries to add extensions to *Electron* and to download them from the *Chrome Web Store*, but there are some licensing limitations and I preferred to roll my own implementation.
:::
