You can search for text within the page:

![Find in page](../../../assets/find-in-page.png)

* Click the cross (1) or press `escape` to exit.
* In the text field (2), enter the text you want to search for.
* If there are multiple results, you can jump to the next or previous (3).
* If the bar is already open and you trigger the command again, the current text stays selected, so you can type a new term to replace it.
