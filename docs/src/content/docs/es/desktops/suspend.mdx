<FeatureAccess entity="suspender un escritorio" command="Suspend Desktop" contextMenu="Suspend all tabs" />

Esta acción suspenderá todas las pestañas activas del escritorio.

A diferencia de suspenderlas [pestaña a pestaña](/es/tabs/close/#suspender), aquí suspendes todo el escritorio de una sola vez. Las pestañas suspendidas ocupan menos memoria y recursos, y se pueden recuperar fácilmente.
