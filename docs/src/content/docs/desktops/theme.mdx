Desktop visual themes let you assign a different theme to each of them so you can differentiate them more easily.

For example, you can have the blue theme on desktop 1 and the purple one on 2.

![Blue theme](../../../assets/desktop-theme-1.jpeg)

![Purple theme](../../../assets/desktop-theme-2.jpeg)

<FeatureAccess entity="desktop theme" command="Desktop Theme" contextMenu="Change theme" />

A modal appears with the list of available themes:

![Theme selection](../../../assets/desktop-theme-3.png)

:::note
Remember that you can modify or add more themes in the [configuration](/config/themes/).
:::
