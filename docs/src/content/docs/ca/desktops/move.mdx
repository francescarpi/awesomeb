Pots moure'l a la dreta o a l'esquerra dins del llistat d'escriptoris. La numeració s'actualitza automàticament per a mantenir l'ordre correlatiu.

## Arrossegar i deixar anar

També pots arrossegar un escriptori sobre un altre per intercanviar les seves posicions. L'escriptori que arrosseges segueix el punter com un cercle, i l'escriptori sobre el qual el deixes queda resaltat per mostrar on caurà.

La numeració s'actualitza automàticament per a mantenir l'ordre correlatiu.
