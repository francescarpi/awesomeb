---
title: Descargas
---

Puedes acceder a las descargas haciendo clic en el icono situado en la parte inferior del panel izquierdo.

![Acceder a descargas](../../../../assets/downloads-1.png)

Verás el número de descargas sobre el icono si hay alguna.

![Número descargas](../../../../assets/downloads-2.png)

Una vez abierto verás una vista así:

![Vista descargas](../../../../assets/downloads-3.png)

Donde podrás:

* Las descargas finalizadas se mostrarán con el porcentaje al 100%. Se muestra el botón de una lupa (1) para mostrarte el finder/explorador.
* Si una descarga está en curso:
  * Podrás pausarla (2)
  * O detenerla (3)
* Limpiar todas las descargas finalizadas (4)
* Si quieres abrir la vista como pestaña nueva pulsa "view all" (5)

![Vista descargas](../../../../assets/downloads-4.png)

:::note
Recuerda que puedes modificar la ruta donde se guardan las descargas en la [configuración](/es/config/general/#carpeta-de-descargas).
:::
