You can also edit it by clicking on the address bar. I know this isn't the expected behavior, since you'd normally expect a free-form text field.

You'll see a modal with two modification options:

![URL edit modal](../../../assets/tab-edit-url.png)

1. **Simple modification**: you change or paste the new URL.
2. **Complex modification**: the URL is split into parts, letting you modify just the part you want. You can also add or modify the *queryparams*.
