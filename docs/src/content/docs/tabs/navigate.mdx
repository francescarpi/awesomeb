Here you'll find the different ways you have to navigate between tabs.

First of all, though, you need to know the concept of **tab container**.

![Tab container](../../../assets/nav-tab-1.png)

A *tab container* is a container that can hold several tabs. For example, if you *split* two websites (2), the *tab container* contains both (one on the left and the other on the right).

Each *tab container* is numbered(1) from 1 to 9. This number/index will let you navigate to it directly with the key combination:

* macOS: `Cmd+<index>`

:::note
If you access a tab where you already are, you'll return to the previous tab. For example: if you're on tab 3, you access 1 and access 1 again, you'll return to 3.
:::

## Previous/Next

If you want to move between the previous and next tab:

* macOS: `Cmd+[` or `Cmd+]`

:::note
These combinations are the default ones as long as you have the `Generic ISO` configuration.
:::

## Tab switcher

The *tab switcher* is the typical component that, when you press `Ctrl+Tab` or `Ctrl+Shift+Tab`, shows you a list of the open tabs to navigate between them.

![Tab switcher](../../../assets/nav-tab-2.png)

:::note
Tabs are ordered by the time of last access. This way you can easily toggle between the current tab and the last one you visited.
:::

## Search for a tab

With the following key combination a modal appears with all tabs (active and suspended):

* macOS: `Cmd+.`

![Search for a tab](../../../assets/nav-tab-3.png)

## Marks

**AwesomeB** introduces a mark system to quickly access the tabs you use most often.

![Marks](../../../assets/nav-tab-4.png)

With the following shortcut, a small information box appears (bottom right):

* macOS: `Cmd+;`

Once open, you can (without releasing `Cmd`):

* Pressing `m+<letter>` creates a new mark associating the letter with the active tab.
* Pressing `<letter>` only, you'll access the associated tab.
* Pressing `n` deletes the mark from the active tab.
* Pressing `b` deletes all marks.

## Requires attention

If you're on a desktop (for example 2) and on 1 there is a tab that requires attention, the desktop will be shown in red.

![Tab requires attention](../../../assets/nav-tab-5.png)

Pressing the following shortcut will take you directly to the tab:

* macOS: `Cmd+u`

The affected tab will have an alert icon, in red.

![Tab requires attention](../../../assets/nav-tab-6.png)

:::note
Being on the tab that required attention, if you press `Cmd+u` again you'll return to the previous tab you came from.
:::

:::note
A tab that requires attention means it has changed its *favicon*, title, or emitted a sound.
:::

## Toggle

There's also a specific key combination to quickly toggle (without using the tab switcher) between the last used tab:

* macOS: `Cmd+'`
