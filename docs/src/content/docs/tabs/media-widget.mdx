---
title: Media Widget
---

If you're on a website that has a *MediaSession*, for example *Youtube*, and you go to another one, the following widget will appear at the bottom of the left panel (*sidebar*) which will let you manage it.

![Media widget](../../../assets/tab-media-widget.jpeg)

1. By clicking on the *favicon* you'll return to the website that's playing the *MediaSession*.
2. You can pause or play the media.
3. You can mute/unmute the audio.
